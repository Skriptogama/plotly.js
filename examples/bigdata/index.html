Progressive 60-Series Plotly Repro

This page appends 60 series with 2500 points each using Plotly.addTraces. It can switch between SVG scatter and WebGL scattergl, with or without a range slider, then logs how long each append takes and summarizes how append time changes as the chart grows. Enable labels and switch Label Position to auto to compare collision-aware point labels against fixed text anchors.

Open devtools to compare browser timing with the in-page log. This sample uses the local GL-capable bundle at dist/plotly-gl2d.js. The label demo preset switches to fewer series and sparse callouts so auto placement stays readable while progressive adds still run through the same code path. Modebar controls now let you compare position, orientation, and hover-position visibility behavior.
